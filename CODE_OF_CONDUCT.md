# Code of conduct

ClipCook follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep feedback about the work. Harassment of any kind is not tolerated.

Report unacceptable behavior through a [private security advisory](https://github.com/slukedev/clipcook/security/advisories/new) marked "Conduct". Reports are handled confidentially.
