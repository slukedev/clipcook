# ClipCook — Impeccable Design Context

## Design Context

### Users
Home cooks saving recipes they find around the web. Two contexts: **browsing/curating** (couch, desktop or phone, unhurried) and **cooking** (kitchen, phone or tablet propped up, wet or floury hands, glancing from arm's length). The cooking context drives the hard requirements: large tap targets, high-contrast checklists, screen wake lock, servings scaling without mental math.

### Brand Personality
Fresh, precise, quietly delightful. "If the Google Material team designed a recipe keeper." The interface should feel like a first-party Google app: calm surfaces, confident type, expressive shape and motion in exactly the right places — never decoration for its own sake.

### Aesthetic Direction
**Material 3 Expressive, by the book — this is an explicit user requirement and overrides generic anti-convergence rules.**
- Typography: Roboto Flex (variable; opsz/wdth/GRAD axes). M3 typescale, emphasized weights for expressive moments.
- Color: M3 dynamic color. Baseline seed #6750A4; every recipe re-themes its detail page from its photo's seed color (server-extracted, both schemes). Light + dark, system-following with manual override.
- Shape: M3 Expressive shape scale — generous corner radii, shape morphing on press, squircle/scallop accents for playful moments (step numbers, empty states).
- Motion: M3 Expressive springs (spatial/effects) via `motion`; state layers and container transforms, not gratuitous parallax.
- Icons: Material Symbols (inlined SVG, outline + fill pairs for state changes).

### What distinguishes it from "AI slop M3"
Real M3 craft is in the details most clones skip: correct state layers on every interactive surface, tonal surface containers instead of shadows-everywhere, per-component shape tokens, emphasized type only where hierarchy earns it, dynamic color that actually derives from content, checklist rows sized for kitchen use, motion that settles like physics not tweens.

### Design Principles
1. **Content-first surfaces** — recipe photos and text carry the color story; chrome stays tonal and quiet.
2. **Kitchen-proof ergonomics** — 48dp minimum targets, checklist rows ≥56dp, readable at arm's length.
3. **No dead states** — empty, loading, error, and offline states teach and charm (Belle the cat is the app's mascot voice).
4. **Physics, not tweens** — every movement uses M3 expressive springs; reduced-motion collapses to instant.
5. **Never block paint on JS** — primary content is visible in SSR HTML; animation enhances from a visible state, not from opacity 0.
6. **Whole-screen layouts** — compact/medium/expanded/large window classes each get a designed layout (list→grid→multi-pane), not a stretched phone view.
